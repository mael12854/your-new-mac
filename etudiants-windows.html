Étudiants venus de Windows

Vous connaissez déjà Windows et vous passez au Mac pour vos études ? Voici ce qui compte pour suivre les cours sans accroc.

Au programme

  1. Retrouver vos repères

    Le plus gros changement tient en une phrase : Ctrl devient ⌘. Pour le reste (Finder, Dock, fermer une app avec ⌘ + Q…), tout est sur la page Vous venez de Windows.

  2. Vos fichiers Word, Excel et PowerPoint

    • Microsoft Office existe sur Mac. Si votre école vous le fournit, connectez-vous à Microsoft 365 avec votre adresse étudiante et installez-le : vos fichiers s’ouvrent comme avant.
    • Sans Office, Pages, Numbers et Keynote (gratuits) ouvrent les fichiers .docx, .xlsx et .pptx. La mise en page peut légèrement bouger : vérifiez avant de rendre.
    • Vos fichiers sur OneDrive : installez l’app OneDrive sur le Mac pour les retrouver dans le Finder.

    Si vous utilisez Pages, envoyez toujours vos devoirs en Word ou en PDF (Fichier > Exporter vers). Un fichier .pages ne s’ouvre pas sur un PC Windows.

  3. Les logiciels de cours

    Plateformes de cours, Teams, Zoom, messagerie de l’école : tout fonctionne sur Mac, dans le navigateur ou via leur app.

    Certains logiciels spécialisés n’existent pourtant que sur Windows (en ingénierie, architecture ou comptabilité, par exemple). Dans ce cas :

    • cherchez s’il existe une version Mac ou en ligne ;
    • demandez à votre école : beaucoup proposent des salles informatiques ou un accès à distance à des PC ;
    • en dernier recours, un logiciel de virtualisation permet de faire tourner Windows sur le Mac. Renseignez-vous auprès de votre école avant d’acheter quoi que ce soit.

    Avant la rentrée, regardez la liste des logiciels demandés dans votre formation : vous saurez tout de suite si l’un d’eux pose problème.

  4. Travailler avec des camarades sur PC

    • Pour les projets de groupe, travaillez en ligne : Word en ligne, Google Docs ou Google Slides fonctionnent pareil sur Mac et sur PC.
    • Clé USB partagée : une clé formatée pour Windows (NTFS) peut être lue sur Mac, mais pas modifiée. Formatez-la en exFAT avec l’app Utilitaire de disque pour qu’elle marche partout. Attention, formater efface son contenu.
    • Envoyer de gros fichiers : partagez un lien OneDrive, Google Drive ou iCloud Drive plutôt qu’une pièce jointe.

  5. Et ensuite

    Ranger ses cours, sauvegarder, rendre un devoir en PDF, verrouiller l’écran à la bibliothèque : tous ces réflexes sont dans le guide étudiant.
