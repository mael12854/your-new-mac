  1. Les touches spéciales

    Ces touches ne font rien seules. On les maintient enfoncées pendant qu’on appuie sur une autre touche.

    Ctrl Contrôle
    La plus utilisée. Elle sert à presque tous les raccourcis : copier, coller, enregistrer…
    ⊞ Windows
    Seule, elle ouvre le menu Démarrer. Combinée à une autre touche, elle lance des actions de Windows.
    Alt
    Sert à quelques raccourcis, comme passer d’une fenêtre à l’autre.
    Alt Gr
    À droite de la barre d’espace. Elle donne le troisième caractère de certaines touches : @, €, #…
    ⇧ Majuscule
    Écrit une lettre en majuscule ou le caractère du haut d’une touche.
    ⌫ Retour arrière et Suppr
    Retour arrière efface le caractère à gauche du curseur, Suppr celui à droite.

  2. Les raccourcis à connaître

    Maintenez la première touche, appuyez sur la suivante, puis relâchez tout.

    Raccourcis clavier courants
    Touches Action
    Ctrl + CCopier
    Ctrl + XCouper
    Ctrl + VColler
    Ctrl + ZAnnuler la dernière action
    Ctrl + ATout sélectionner
    Ctrl + SEnregistrer
    Ctrl + FChercher un mot
    Alt + TabPasser d’une fenêtre à l’autre
    Alt + F4Fermer la fenêtre
    Ctrl + ⇧ + ÉchapOuvrir le Gestionnaire des tâches (pour fermer une app bloquée)

  3. Les raccourcis avec la touche Windows

    Raccourcis avec la touche Windows
    Touches Action
    ⊞ + EOuvrir l’Explorateur de fichiers
    ⊞ + DAfficher le bureau
    ⊞ + LVerrouiller l’ordinateur
    ⊞ + IOuvrir les Paramètres
    ⊞ + ⇧ + SFaire une capture d’écran
    ⊞ + VHistorique du copier-coller
    ⊞ + ← ou →Placer la fenêtre sur la moitié gauche ou droite de l’écran
    ⊞ + .Ouvrir les emojis et les symboles

    Vous partez ? ⊞ + L verrouille l’écran en une seconde.

  4. Taper @, €, \ et les autres

    Sur un clavier français (AZERTY), ces caractères sont gravés en petit sur les touches, et s’obtiennent avec Alt Gr.

    Caractères spéciaux sur clavier PC français
    Touches Caractère
    Alt Gr + à@
    Alt Gr + E€
    Alt Gr + "#
    Alt Gr + '{
    Alt Gr + ([
    Alt Gr + -|
    Alt Gr + _\

    Pour les majuscules accentuées comme É ou À, ouvrez le panneau des symboles avec ⊞ + ., puis choisissez l’onglet des symboles.
