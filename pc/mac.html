Vous venez du Mac

Vous savez déjà vous servir d’un ordinateur. Il vous suffit de retrouver vos repères : voici ce qui change sur un PC.

  2. ⌘ devient Ctrl

    La règle d’or : presque tous vos raccourcis avec ⌘ fonctionnent avec Ctrl à la place. Ctrl + C copie, Ctrl + V colle, Ctrl + Z annule.

    Raccourcis Mac et leur équivalent PC
    Sur Mac Sur PC
    ⌘ + TabAlt + Tab
    ⌘ + QAlt + F4 pour fermer l’app
    ⌘ + Espace⊞ puis tapez votre recherche
    ⌥ + ⌘ + ÉchapCtrl + ⇧ + Échap (Gestionnaire des tâches)
    ⌘ + ⇧ + 5⊞ + ⇧ + S (capture d’écran)
    ⌃ + ⌘ + Q⊞ + L (verrouiller)
    ⌘ + ⌫ sur un fichierSuppr
    Entrée pour renommerF2

    La touche ⌥ Option du Mac correspond à Alt. Pour les caractères cachés comme @ ou €, c’est Alt Gr : tous les détails sur la page le clavier du PC.

  3. Fenêtres et apps

    • Les boutons des fenêtres sont à droite : réduire (—), agrandir (□), fermer (×).
    • Fermer la fenêtre quitte en général l’app, contrairement au Mac. Quelques apps (messagerie, stockage en ligne) continuent en arrière-plan : leur icône reste près de l’heure.
    • Les menus sont dans chaque fenêtre, et non dans une barre tout en haut de l’écran.

  4. Gérer ses fichiers

    • Déplacer un fichier : Ctrl + X pour couper, puis Ctrl + V à l’endroit voulu. Le couper-coller marche directement, sans astuce.
    • Voir un fichier sans l’ouvrir : dans l’Explorateur, Alt + P affiche un volet d’aperçu à droite.
    • Installer une app : depuis le Microsoft Store, ou en ouvrant le fichier .exe ou .msi téléchargé sur le site officiel.
    • Désinstaller une app : Paramètres > Applications > Applications installées, puis le menu « … » à côté de l’app.

    Disques formatés pour Mac (APFS ou Mac OS étendu) : Windows ne sait pas les lire. Pour un disque partagé entre Mac et PC, utilisez le format exFAT.

  5. Récupérer vos données

    • Photos et fichiers iCloud : installez l’app iCloud pour Windows depuis le Microsoft Store, puis connectez-vous avec votre identifiant Apple.
    • Le reste : copiez vos dossiers sur un disque externe formaté en exFAT, puis recopiez-les sur le PC.

    Plus simple encore : si vos fichiers sont sur OneDrive, Google Drive ou Dropbox, il suffit de vous connecter sur le PC.
