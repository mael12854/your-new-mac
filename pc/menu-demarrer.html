Le menu Démarrer

Le point de départ de tout sur Windows : vos apps, la recherche et le bouton pour éteindre.

Au programme

  1. L’ouvrir
  2. Ce qu’il contient
  3. Chercher
  4. Épingler vos apps

  1. L’ouvrir

    ⊞win

    Deux façons :

    • appuyez sur la touche Windows du clavier, en bas à gauche, entre Ctrl et Alt ;
    • ou cliquez sur le bouton Démarrer, les quatre carrés au début de la barre des tâches.

    Un nouvel appui sur la touche Windows referme le menu.

  2. Ce qu’il contient

  3. Chercher

    Ouvrez le menu Démarrer et tapez directement, sans cliquer nulle part : le nom d’une app, d’un fichier ou d’un réglage. Appuyez sur Entrée pour ouvrir le premier résultat.

    Exemple : appuyez sur ⊞, tapez « wifi », puis Entrée pour ouvrir les réglages Wi-Fi.

  4. Épingler vos apps

    Faites un clic droit sur une app (dans le menu Démarrer ou dans les résultats de recherche), puis choisissez :

    • Épingler au menu Démarrer, pour l’avoir dès l’ouverture du menu ;
    • Épingler à la barre des tâches, pour l’ouvrir en un clic à tout moment.

    Pour réorganiser, faites glisser les icônes épinglées. Clic droit puis « Détacher » pour en retirer une.
