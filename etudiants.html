Un Mac pour vos études

C’est votre premier ordinateur et vous l’avez pour les cours ? Voici les bons réflexes à prendre dès la rentrée.

Au programme

  1. Apprendre les bases

  3. Ranger ses cours

  5. Rendre un devoir

  1. Apprendre les bases

    Avant tout, prenez dix minutes pour le guide Premiers pas sur Mac : allumer, utiliser le trackpad, ouvrir une app. Puis jetez un œil aux raccourcis clavier : ⌘ + C et ⌘ + V vous serviront tous les jours.

    Vous aviez déjà un PC Windows ? Le guide des étudiants venus de Windows est fait pour vous.

  2. Les logiciels gratuits

    • Pages, Numbers et Keynote sont fournis gratuitement avec le Mac : traitement de texte, tableur et présentations.
    • Microsoft Office (Word, Excel, PowerPoint) : de nombreuses écoles et universités l’offrent à leurs étudiants. Connectez-vous avec votre adresse e-mail étudiante sur le site de Microsoft 365 pour vérifier.
    • Notes, déjà installée, suffit largement pour prendre des notes en cours.

    Votre prof demande un fichier Word ? Dans Pages, choisissez Fichier > Exporter vers > Word.

  3. Ranger ses cours

    Dans le Finder, créez un dossier par année, puis un dossier par matière. Au moment des révisions, vous vous remercierez.

    • Créer un dossier : ⌘ + ⇧ + N dans le Finder.
    • Nommer clairement : « Droit civil – TD3 – 2026-10-20 » plutôt que « Document 4 ».
    • Retrouver un fichier : ⌘ + Espace, puis tapez un mot de son nom.

  4. Sauvegarder (vraiment)

    Un ordinateur peut se perdre, se voler ou tomber en panne. Le jour où ça arrive, vos cours et votre mémoire doivent exister ailleurs.

    • iCloud Drive : rangez vos cours dedans et ils sont copiés en ligne automatiquement. 5 Go sont offerts ; au-delà, l’espace est payant.
    • Time Machine : branchez un disque dur externe, et le Mac fait des sauvegardes complètes tout seul. Réglage dans Réglages Système > Général > Time Machine.

    L’idéal : les deux. Une copie en ligne, une copie sur un disque à la maison.

  5. Rendre un devoir

    La plupart des plateformes de cours préfèrent le PDF : il s’affiche pareil partout.

    • Dans Pages : Fichier > Exporter vers > PDF.
    • Depuis n’importe quelle app : ⌘ + P, puis en bas de la fenêtre, menu PDF > Enregistrer au format PDF.

    Ouvrez toujours le PDF une dernière fois avant de l’envoyer. Il suffit d’appuyer sur Espace dans le Finder pour le prévisualiser.

  6. Au campus

    • Wi-Fi : beaucoup d’établissements utilisent le réseau eduroam, avec vos identifiants étudiants. Suivez les instructions de votre école.
    • Verrouiller l’écran quand vous vous levez à la bibliothèque : ⌃ + ⌘ + Q.
    • Activer Localiser dans Réglages Système, en cliquant sur votre nom puis sur iCloud : vous pourrez retrouver ou bloquer le Mac s’il disparaît.
    • Rester concentré : le mode Concentration coupe les notifications pendant les cours. Il se trouve dans le Centre de contrôle, en haut à droite de l’écran.
