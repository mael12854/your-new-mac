Vous venez de Windows

Vous savez déjà vous servir d’un ordinateur. Il vous suffit de retrouver vos repères : voici ce qui change.

  2. Ctrl devient ⌘

    La règle d’or : presque tous vos raccourcis avec Ctrl fonctionnent avec ⌘ à la place. ⌘ + C copie, ⌘ + V colle, ⌘ + Z annule.

    Raccourcis Windows et leur équivalent Mac

    La touche Alt de Windows correspond à ⌥ Option. Tous les détails sur la page le clavier du Mac.

  3. Fenêtres et apps

    • Les boutons des fenêtres sont à gauche : rouge pour fermer, jaune pour réduire, vert pour agrandir.
    • Fermer une fenêtre ne quitte pas l’app. Elle reste ouverte en arrière-plan, signalée par un petit point sous son icône dans le Dock. Pour la quitter vraiment : ⌘ + Q.
    • Les menus de l’app sont tout en haut de l’écran, dans la barre des menus, et non dans chaque fenêtre.

  4. Gérer ses fichiers

    • Déplacer un fichier (couper-coller) : ⌘ + C, puis ⌥ + ⌘ + V à l’endroit voulu.
    • Voir un fichier sans l’ouvrir : sélectionnez-le et appuyez sur Espace.
    • Installer une app téléchargée : ouvrez le fichier .dmg, puis glissez l’app dans le dossier Applications.
    • Désinstaller une app : dans la plupart des cas, glissez-la du dossier Applications vers la Corbeille.

    Clés USB et disques durs formatés pour Windows (NTFS) : le Mac peut lire leur contenu, mais pas y écrire. Pour un disque partagé entre Mac et Windows, utilisez le format exFAT.

  5. Récupérer vos données

    L’app Assistant migration, fournie avec le Mac, peut transférer vos documents, photos et favoris depuis votre ancien PC. Installez sur le PC l’outil « Assistant migration pour Windows », disponible gratuitement sur le site d’Apple, puis suivez les étapes sur les deux ordinateurs.

    Plus simple encore : si vos fichiers sont déjà sur OneDrive, Google Drive ou Dropbox, installez l’app correspondante sur le Mac et connectez-vous.
