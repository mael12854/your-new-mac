Logiciels pratiques

Le Mac est déjà bien équipé. Ces quelques apps, gratuites pour la plupart, le rendent encore plus agréable.

  1. Transférer des fichiers

    LocalSend Gratuit

    Très pratique : envoie photos, vidéos et documents entre votre Mac et n’importe quel appareil (téléphone Android, iPhone, PC Windows, Linux), sans câble ni compte. Les deux appareils doivent simplement être sur le même Wi-Fi.

    Télécharger sur localsend.org ↗ (nouvel onglet)
    AirDrop Intégré

    Déjà sur le Mac, pour échanger avec un iPhone, un iPad ou un autre Mac. Dans le Finder, cliquez sur AirDrop dans la barre latérale. Pour les appareils Android ou Windows, utilisez LocalSend.

  2. Les indispensables

    The Unarchiver Gratuit

    Ouvre les fichiers compressés que le Mac ne sait pas lire seul, comme les .rar ou les .7z.

    Télécharger sur theunarchiver.com ↗ (nouvel onglet)
    VLC Gratuit

    Lit presque tous les formats de vidéo et d’audio, même ceux que l’app QuickTime refuse.

    Télécharger sur videolan.org ↗ (nouvel onglet)
    IINA Gratuit

    Une alternative à VLC, pensée pour le Mac, avec une interface plus moderne.

    Télécharger sur iina.io ↗ (nouvel onglet)
    AppCleaner Gratuit

    Désinstalle une app proprement, avec tous les fichiers qu’elle a laissés derrière elle. Glissez l’app dans sa fenêtre, puis cliquez sur Supprimer.

    Télécharger sur freemacsoft.net ↗ (nouvel onglet)

  3. S’organiser plus vite

    Rectangle Gratuit

    Place les fenêtres d’un raccourci clavier : moitié gauche, moitié droite, plein écran… Idéal si vous aimiez ranger vos fenêtres sur Windows.

    Télécharger sur rectangleapp.com ↗ (nouvel onglet)
    Maccy Gratuit

    Garde l’historique de tout ce que vous copiez. Vous retrouvez un texte copié il y a une heure en un raccourci.

    Télécharger sur maccy.app ↗ (nouvel onglet)
    Raycast Gratuit, options payantes

    Une version très enrichie de la recherche Spotlight : calculatrice, conversions, gestion des fenêtres et des centaines d’extensions. Plutôt pour quand vous serez à l’aise.

    Télécharger sur raycast.com ↗ (nouvel onglet)

  4. Bureautique

    Pages, Numbers et Keynote sont déjà installés et gratuits. Si vous avez besoin d’autre chose :

    LibreOffice Gratuit

    Une suite bureautique complète et libre (texte, tableur, présentations) qui ouvre les fichiers Word, Excel et PowerPoint.

    Télécharger sur libreoffice.org ↗ (nouvel onglet)
    Microsoft 365 Payant, souvent offert aux étudiants

    Word, Excel, PowerPoint, Outlook et OneDrive, en version Mac. Vérifiez d’abord si votre école ou votre travail vous le fournit.

    Voir sur microsoft.com ↗ (nouvel onglet)

  5. Navigateurs

    Safari, déjà installé, est rapide et économe en batterie. Si vous préférez retrouver votre navigateur habituel :

    Firefox Gratuit
    Télécharger sur mozilla.org ↗ (nouvel onglet)
    Google Chrome Gratuit
    Télécharger sur google.com ↗ (nouvel onglet)

    Installer une app téléchargée : ouvrez le fichier .dmg, puis glissez l’app dans le dossier Applications. Téléchargez toujours depuis le site officiel, comme ceux indiqués ici. Beaucoup de ces apps existent aussi sur l’App Store.
